STUDYHUB — DEMONSTRATION PROJECT
================================
This is a local college-project demo. It does not create a real public website/domain.

Run on Ubuntu:
1. Extract this ZIP.
2. Open Terminal in the extracted studyhub_project folder.
3. Run these commands one at a time:

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py

4. Keep Terminal open. In Firefox/Chrome open:
http://127.0.0.1:5000

How to demonstrate:
- Register as a Teacher with your demo name/email and a password of 8+ characters.
- Log in using that same email and password.
- Click Upload Notes. Add a title and a subject such as Maths, Science or PSPC.
- Choose a small PDF/PPT/DOC file and upload it.
- Log out.
- Register as a Student with a different email.
- Log in and download the uploaded note from Notes or Dashboard.

Important:
- Use only made-up/demo accounts for class presentation.
- Files and accounts are stored locally on this laptop.
- Both student and teacher registration are enabled for this prototype.
